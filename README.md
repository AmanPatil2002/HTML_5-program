# HTML5 Program Examples

This workspace contains a set of HTML5 example files demonstrating common HTML5 elements and semantic tags. Each file is a standalone sample showing tag usage, simple content, or browser behavior.

## Files

- `article.html`
  - Demonstrates the `<article>` semantic element.
  - Contains four article blocks with heading and placeholder text.

- `aside.html`
  - Shows the `<aside>` element used for a secondary or sidebar section.
  - Contains a list of radio button categories.

- `audio.html`
  - Demonstrates the HTML5 `<audio>` element.
  - Uses `controls`, `loop`, `autoplay`, and `muted` attributes to play an audio file from `assets`.

- `bdo-tag.html`
  - Shows the `<bdo>` element for text direction override.
  - Contains a `p` element with `bdo dir="rt1"` applied to the text.

- `blockquote.html`
  - Demonstrates the `<blockquote>` element for quoted content.
  - Includes a `cite` attribute referencing an external source.

- `canvas.html`
  - Demonstrates the HTML5 `<canvas>` element.
  - Includes JavaScript to change the canvas background color when a button is clicked.

- `code.html`
  - Shows the `<code>` element to mark inline code text.
  - Uses simple styling for the `code` tag.

- `datalist.html`
  - Demonstrates the `<datalist>` element.
  - Includes a text input with auto-complete suggestions for city names.

- `details.html`
  - Demonstrates the `<details>` and `<summary>` elements.
  - Provides expandable disclosure content for copyright information.

- `dialog.html`
  - Demonstrates the HTML5 `<dialog>` element.
  - Displays a simple open dialog box.

- `figure-figcaption.html`
  - Demonstrates the `<figure>` and `<figcaption>` elements.
  - Contains an image and caption describing the picture.

- `form.html`
  - Demonstrates many HTML5 form input types.
  - Includes `color`, `date`, `month`, `range`, `number`, `image`, `hidden`, `tel`, `search`, and a submit button.

- `layout.html`
  - Demonstrates common page structure with semantic layout tags.
  - Includes `header`, `main`, and `footer` sections.

- `mark.html`
  - Demonstrates the `<mark>` element.
  - Highlights a word inside a paragraph.

- `meter.html`
  - Demonstrates the `<meter>` element.
  - Shows a gauge style indicator with `min`, `max`, and `value` attributes.

- `progres.html`
  - Demonstrates the `<progress>` element.
  - Displays a progress bar with a set value.

- `section.html`
  - Demonstrates multiple `<section>` elements.
  - Includes repeated section blocks and a footer.

- `svg.html`
  - Demonstrates inline SVG graphics.
  - Contains a simple circle and additional SVG shapes with gradients.

- `vedio.html`
  - Demonstrates the HTML5 `<video>` element.
  - Uses `controls`, `autoplay`, `loop`, and `muted` attributes to play a video from `assets`.

- `wbr.html`
  - Demonstrates the `<wbr>` (word break opportunity) element.
  - Contains a long text example with word break opportunities inserted.

## Assets

- `assets/`
  - Contains media files referenced by the examples, such as audio, video, and images.

## Usage

Open any file in a browser to view the HTML5 demonstration. Most examples focus on a single HTML5 element or semantic structure to illustrate its purpose.
